数据、执行和复现说明
订单、产品、供应商、规则与通知均为人工构造样例；不代表真实业务数据。风险分值仅用于演示。规则来自 Markdown 中声明的 JSON 块；通知状态来自 annotations.json 中的人工标注，不是模型自动理解的结果。v1/v2 展示知识更新如何改变任务结果，不构成遗忘或反学习测试。
网页执行器读取已导出的 IR 行、图边和规则。Python 端另有只读 SQLite 执行器；本网页不运行原生 SQL。所有联合关系由配置显式声明。小规模对象保存在 manifest 中；大图使用 Parquet 集合分批读取，保留原候选集与评分协议。原 hub 和评分器仍保留全量查询 ID，整体内存并非仅由 batch 决定。图片 OCR 不提供场景理解，PDF 原生文本提取也不代表图表理解。
